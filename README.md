## 项目简介

本项目针对工业循环水系统的智能控制问题，采用数据驱动方法，结合 LSTM 系统建模、SVM 代理模型、遗传算法（GA）优化和深度强化学习（DRL），实现了循环水系统流量和温度的精确控制。

## 技术路线

1. **数据预处理**：企业真实传感器数据（28天，52万+条记录），包括清洗、去噪、标准化
2. **LSTM 系统建模**：3层双向 LSTM（128隐藏单元），预测系统状态演变
3. **SVM + GA 优化**：SVM 代理模型加速适应度评估（~10,000x），GA 离线寻优
4. **DRL 智能控制**：DDPG + 行为克隆预训练 + 物理引导实时修正
5. **闭环仿真验证**：GA 100%/100%/100%，DRL 100%/100%/100%

```
├── drl_controller.py      # DDPG 智能体 + 行为克隆
```


## 数据准备

由于数据量较大（2.4GB），原始传感器数据未包含在 Git 仓库中。运行前需将 `shuju/` 目录放置到项目根目录：

```
shuju/
├── FB/    # FB 数据文件（.csv）
└── TP/    # TP 数据文件（.csv）
```

## 运行

```bash

python run_thesis_v2.py

python generate_thesis.py
```
